# ComputacionGrafica

Proyecto de prácticas y ejercicios de Computación Gráfica utilizando OpenGL

---

## Tecnologías Utilizadas

- C++
- OpenGL
- GLSL
- GLFW
- GLAD
- Visual Studio

---

## Requisitos

Antes de ejecutar el proyecto asegúrate de tener instalado:

- Visual Studio 2019 o superior
- OpenGL
- GLFW
- GLAD
- Drivers gráficos actualizados

---

## Ejecución

1. Clonar el repositorio:

```bash
git clone https://github.com/TU_USUARIO/ComputacionGrafica.git
```

2. Abrir la solución en Visual Studio.

3. Compilar en modo:

```bash
x64 / Debug
```

4. Ejecutar el archivo o proyecto deseado.

---

## Contenido

El repositorio incluye ejercicios relacionados con:

- Renderizado 2D y 3D
- Buffers (VBO, VAO, EBO)
- Shaders
- Texturas
- Transformaciones
- Modelos 3D
- Animaciones básicas
